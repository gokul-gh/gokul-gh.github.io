Pandit Connect is a Progressive Web Application (PWA) that connects users with pandit services and facilitates online bookings. The application provides a seamless cross-platform experience while leveraging Spring Boot for backend reliability.

Key capabilities:
- User authentication and profile management
- Service browsing and discovery
- Online booking and scheduling
- PWA capabilities for offline access and mobile experience
- RESTful API integration between React frontend and Spring Boot backend
