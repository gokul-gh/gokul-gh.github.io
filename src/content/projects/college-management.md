This College Management System streamlines academic operations by centralizing student, staff, and course data. Built with reusable React components for a responsive frontend and Spring Boot for robust backend services.

Key capabilities:
- Student and staff profile management
- Academic operations tracking
- Role-based access for different user types
- Secure API integration between React frontend and Spring Boot backend
